# OneCode - OSS (Simple code editor made in Python)

## Download for Windows (11,10, etc.)
### You have to run the code manually because I can't get .exe on my Arch Linux ahh laptop.
```python3 main.py```

## Download for Linux (Ubuntu, Arch, openSUSE etc.)
### Download for Arch Linux (AUR) using ```yay -S onecodeoss-bin```, ```aurx inst onecodeoss-bin``` or any AUR helper. You can also download the .AppImage file, and run it:
```chmod +x OneCode-1.AppImage```
```./OneCode-1.AppImage```

You need to have latest Python installed, PyQt6, pygments



Read the code for more info.
